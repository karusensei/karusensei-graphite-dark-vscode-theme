# Échelle de gris

Tous les gris de l'interface sont neutres (`R = G = B`). Les commentaires de la
syntaxe (`#636d83`, `#7c8495`) et les couleurs du terminal restent hors de cette
échelle.

| Hex       | Emploi principal                                        |
| --------- | ------------------------------------------------------- |
| `#ffffff` | Texte sur accent, badges                                |
| `#b1b1b1` | Texte principal, icônes                                 |
| `#7f7f7f` | Titres de panneaux inactifs                             |
| `#797979` | Fichiers ignorés par Git                                |
| `#6c6c6c` | Texte secondaire, onglets inactifs, fil d'Ariane        |
| `#606060` | Zone de dépôt d'un groupe d'éditeurs                    |
| `#585858` | Texte indicatif des champs                              |
| `#464646` | Barre de titre                                          |
| `#434343` | Bordures                                                |
| `#3f3f3f` | Onglet actif « modern »                                 |
| `#3a3a3a` | Repère d'indentation du bloc courant                    |
| `#373737` | En-têtes de section, bouton secondaire survolé          |
| `#323232` | Barre d'activité, barre d'état, ligne courante          |
| `#2e2e2e` | Onglet survolé                                          |
| `#2c2c2c` | Champs de saisie, notifications, widgets                |
| `#272727` | Barre d'outils de débogage                              |
| `#262626` | Règles verticales, repères d'indentation                |
| `#252525` | Barre d'onglets, onglets inactifs                       |
| `#242424` | Listes déroulantes, cases à cocher                      |
| `#1c1c1c` | Séparateurs d'onglets                                   |
| `#1a1a1a` | Bordures des groupes et de la barre latérale, ombres    |
| `#181818` | Fond de l'éditeur, des panneaux, onglet actif           |
| `#000000` | Fonds transparents (`#00000000`)                        |
